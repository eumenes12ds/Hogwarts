# 脱獄方案

## 内蔵脱獄を使用

変数更新を担当するAIに、MVU内蔵のプロンプトを使用します。提供者は @离 です。主にGeminiとClaudeを想定し、ほかのモデルでも利用できます。

## 現在のプリセットを使用

現在のプリセットのプロンプトを変数更新用AIへ送信します。ただし、プリセットに執筆指示があると、変数の更新だけでなく物語の続きを生成する場合があります。その場合、更新結果が現在の返信ではなく、先の展開に対応してしまうことがあります。

## その他のプリセットを使用

指定した保存済みプリセットのプロンプトを、その順序で送信します。SillyTavernで使用中のプリセット自体は切り替えないため、切り替えに伴う接続変更、コールバックやチャット再読み込みは発生しません。

- 読み取るのは保存済みの内容です。現在の画面にある未保存の `in_use` の変更は含みません。
- 正規表現は現在の環境を使用し、指定先のプリセットのものには切り替えません。
- モデル出典が「カスタム」の場合、APIアドレス、モデル名、温度などはMVUの追加モデル設定を使用します。
- 適用するのはプロンプトだけです。指定先の独自スクリプトやAPI設定は適用しません。
