# 応答フォーマット

応答形式によって、追加モデル解析で必要なAPI機能と更新結果の安定性が変わります。

- **チャットメッセージ**：互換性が最も高く、特別なAPI機能は不要です。指定した形式をモデルが守るかどうかに安定性が左右されます。
- **ツール呼び出し**：tools/function calling対応が必要です。本文の混入を減らせますが、非対応のモデルやプロキシではエラーや機能低下が起こります。
- **フォーマット出力**：OpenAI互換の `response_format.json_schema` が必要です。構造化JSONに制約できるため、通常はJSONPatchの更新に適しています。
- **フォーマット出力（v4互換）**：dsv4fなど、`response_format.type = json_object` のみ対応する接続先向けです。モデル出典が**カスタム**の場合のみ使えます。

`response_format.json_schema` 対応が確認できる場合はフォーマット出力を試してください。非対応ならv4互換またはチャットメッセージを選びます。tools/function calling対応ならツール呼び出しも使用できます。
